# Итоговый проект по анализу данных — Python

## Описание проекта

В данном проекте выполнен анализ данных с использованием Python и библиотеки Pandas. Работа включает обработку данных, группировку, расчёт показателей продаж и визуализацию результатов.

Дополнительно проведён анализ зависимости динамики продаж от температуры воздуха в Астане за 2018 год.

## Используемые инструменты

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Выполненные задачи

1. Загрузка и изучение исходных данных из CSV.
2. Проверка типов данных и преобразование столбца с датами.
3. Группировка данных по датам и расчёт ежедневного количества проданных товаров.
4. Построение графика динамики продаж.
5. Анализ трендов, колебаний и аномальных значений продаж.
6. Поиск строки с максимальным количеством проданных товаров.
7. Определение самого продаваемого товара по средам за июнь, июль и август для склада №3.
8. Обработка архива погоды в Астане и расчёт средней температуры по дням.
9. Объединение данных о продажах и температуре.
10. Построение совместного графика продаж и температуры, а также отдельного графика температуры.

## Основные результаты

- Выявлена общая положительная динамика ежедневных продаж.
- Обнаружены регулярные колебания продаж и отдельные аномальные значения.
- Максимальное количество товара в одной записи составляет 200 единиц.
- Самый продаваемый товар по средам за июнь–август на складе №3 — `product_1`, 2267 единиц.
- Построены графики для визуального сравнения продаж и температуры воздуха.

## Файлы проекта

- `Блок 3.ipynb` — Jupyter Notebook с кодом, графиками и выводами.
- `data.csv` — исходные данные о продажах.
- `Astana Weather Archive.csv` — архив погодных наблюдений.

## Запуск проекта

1. Установить Python и Jupyter Notebook.
2. Установить необходимые библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`.
3. Скачать файлы репозитория в одну папку.
4. Открыть `Блок 3.ipynb` в Jupyter Notebook.
5. Последовательно выполнить все ячейки.
